Manual de Instruções

Como usar um controle de videogame:

Este manual ensina como utilizar um controle de videogame sem que o estrague, e irei usar o exemplo do ps5

Como usar:

  1. Pressione o botão central do controle, isso faz o playstation ligar.
  2. Aguarde a conexão.
  3. Utilize os botões do controle para jogar.

Cuidados:

  • Não molhar o controle.
  • Evitar quedas.
