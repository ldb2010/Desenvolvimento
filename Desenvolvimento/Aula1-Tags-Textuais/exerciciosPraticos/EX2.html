Função Quadrática

O que é uma Função Quadrática?

Uma função do 2º grau é uma função polinomial representada pela equação:
f(x) = ax2 + bx + c, onde a, b e c são números reais e seu gráfico é uma parábola.

Características:

  • O gráfico é uma parábola.
  • Se a > 0, a parábola é voltada para cima.
  • Se a < 0, a parábola é voltada para baixo.
  • O valor de c indica onde o gráfico corta o eixo y.

Exemplo:

Exemplo de função: f(x) = x2 - 4x + 3.
